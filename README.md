# 无人机航拍目标检测：VisDrone + YOLO11 对比实验

## 项目背景

基于 YOLO11 在 VisDrone 航拍数据集上进行目标检测，针对小目标检测难题，
设计了分辨率和 P2 检测头两组对比实验。

VisDrone 的特点：
- 目标极小（平均约 22 像素）
- 场景密集（验证集平均每张约 70 个目标）
- 类别不平衡（car 样本数是 awning-tricycle 的 27 倍）

## 实验设计

所有实验均在 VisDrone 上训练 50 轮，使用 YOLO11n 模型。
严格控制变量，每组对比只改一个参数。

| 实验  | imgsz | batch | 检测头 | 预训练 | 目录名 |
|------|-------|-------|--------|-----|--------|
| 基线 640 | 640 | 8     | 标准 | 是   | baseline_640-b8 |
| 基线 640 (控制变量) | 640 | 是     | 标准 | 是   | baseline_640_b4 |
| 高分辨率 960 | 960 | 4     | 标准 | 是   | baseline_960_b4 |
| P2 从零训练 | 640 | 4     | P2 | 否   | yolo11n_p2_640 |
| P2 + 预训练 | 640 | 4     | P2 | 是   | yolo11n_p2_640_pretrained |

## 核心结果

| 实验 | mAP50 | mAP50-95 |
|------|-------|----------|
| 基线 640 | 0.303 | 0.168 |
| 基线 640 (batch=4) | 0.302 | — |
| 高分辨率 960 | **0.404** | 0.236 |
| P2 从零训练 | 0.226 | 0.123 |
| P2 + 预训练 | 0.293 | 0.161 |

## 核心结论

1. **分辨率提升最有效**：imgsz 从 640 提到 960，mAP50 提升 34%（0.302→0.404）。
   - 小目标提升尤其明显：bicycle 从 0.069→0.137（+98%），awning-tricycle 从 0.096→0.177（+84%）
   - 大目标提升较小：car 从 0.724→0.809（+12%）
   - 代价：训练时间从 0.95h 涨到 2.03h，推理速度从 1.4ms 降到 2.2ms

2. **P2 检测头收益不明显**：P2 + 预训练 mAP50=0.293，低于基线 0.302。
   - 原因：VisDrone 训练数据仅 6471 张，P2 检测头需要更多数据才能学好
   - 代价：推理速度从 1.4ms 涨到 4.6ms（慢 3.3 倍），但 mAP 没涨
   - 结论：在数据规模有限的情况下，加检测头不如提高分辨率划算

3. **预训练对 P2 至关重要**：P2 从零训练 mAP50=0.226，加预训练后涨到 0.293（+30%）。
   - 说明迁移学习在目标检测中比结构改进更关键

## 实验的局限

- P2 检测头官方没有发布预训练权重，使用 `.load()` 从标准 YOLO11 迁移，
  新增的 P2 检测头仍需从零训练
- 由于显存限制，部分实验的 batch 不同（8 vs 4），已通过补跑 batch=4 的基线验证：
  batch 从 8 降到 4 对 mAP50 影响仅 0.001，不是主导因素

## 环境

- Python 3.11.16
- ultralytics 8.4.160
- PyTorch 2.5.1 + CUDA 12.1
- GPU: NVIDIA RTX 4060 Lapop (8GB)

## 运行方式

```bash
# 1. 安装依赖
pip install ultralytics

# 2. 下载数据集（首次运行自动下载，约 2GB）
python 02_check_dataset.py

# 3. 训练基线
python 03_train_baseline.py

# 4. 下载 P2 配置并训练
python 04_download_p2.py
python 06_train_p2_pretrained.py
